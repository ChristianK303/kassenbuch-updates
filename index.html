Service-Tools für Epson-Drucker

Epson Service Tool (einfach)

  • EpsonServiceTool.exe (23 MB, empfohlen, ohne Installation)
  • EpsonServiceTool.zip (30 MB, Quelltext-Version mit start.bat und Python-Installer)

Status, Tintenstände, Zähler, Düsentest, Reinigung und Resttintenzähler – per USB oder Netzwerk, für rund 580 Epson-Modelle. Das Modell des gewählten Druckers wird automatisch erkannt. Die exe in einen Ordner legen und doppelklicken; Windows kann beim ersten Start warnen („Weitere Informationen“ → „Trotzdem ausführen“). Die ZIP-Version braucht Python: entpacken, bei Bedarf python_installieren.bat, dann start.bat.

Epson-Druckerkonfiguration (für Fachleute)

  • DruckerTankwart_EpsonConfig.exe (25 MB, ohne Installation)
  • Quelltext (0,4 MB)

Mehr Funktionen (EEPROM lesen/schreiben, Schlüssel erkennen, Testdrucke), deutsche Oberfläche, rund 580 Modelle mit automatischer Modellerkennung. Windows kann beim ersten Start warnen, weil die Datei nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“. Vorsicht beim Schreiben ins EEPROM: ein falsches Modell kann den Drucker unbrauchbar machen.

Beide Tools beruhen auf epson_print_conf von Ircama (Lizenz EUPL-1.2, liegt den Downloads bei).
